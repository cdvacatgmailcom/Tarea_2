# Tarea_2
Vaca_Carlos_POO_U2

Objetivos del Proyecto

Ampliar y mejorar un proyecto Java utilizando conceptos avanzados de Programación Orientada a
Objetos (POO), tales como herencia, asociación, agregación, y composición. Al final de esta
actividad, los estudiantes habrán integrado nuevas clases en un proyecto existente, creado un
diagrama de clases, y desarrollado un sistema funcional. También aprenderán a gestionar proyectos
en GitHub.
